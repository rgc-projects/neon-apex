# NEON APEX — 赛道设计与街机漂移手感工程规范

本文档永久保存我们在反复调研现代街机赛车（*Forza Horizon*、*OutRun 2*、*Need for Speed Heat*、*Mario Kart*、*Gran Turismo 7*）以及多轮全赛道物理仿真验证后沉淀下来的**赛道建模标准、漂移物理参数与验收清单**。后续每次新增或调整赛道，均应遵循本规范。

---

## 一、 赛道几何与比例规范（Modern Highway Proportions）

1. **推荐尺度与路面宽度**
   - 基准控制点在 `scalePoints(pts, 1.55, 1.15)` 下展开，单圈实测长度控制在 **`3,300m – 4,300m`**（单圈高速完赛时间约 `32s – 44s`，3 圈总时长约 `1分40秒 – 2分15秒`）。
   - 路面宽度 `roadWidth` 控制在 **`26m – 32m`**（双向四车道 + 路肩规模），保证 6 车并排超车、外-内-外走线与大角度横滑（35°–40°）时拥有充足容错空间。
   - `TrackSpline` 统一使用闭环向心 Catmull-Rom 样条，采样密度 `sampleCount = 1500`（每段步长 ~2.4m），保证高车速（400+ km/h）下曲率与坡度平滑无折角。

2. **弯道类型与倾角（`inwardBankDeg`）控制漂移时长机制**
   - 坐标系约定：`[right, up, -tangent]` 为右手系；`curvature > 0` 表示向右转；`inwardBankDeg` 统一填**正角度值**，`TrackSpline` 自动根据曲率符号向弯心倾斜。
   - **小角度 / 平直技术型 U 型弯（`0° – 12°`）**：
     - 弯中速度收敛略强（约 `64%–84%` 极速），保留轻微向外离心推力，玩家需提前外切入弯并积极内打/反打控线。
     - 蓄气速率较快（`bankChargePace ≈ 1.25× – 1.38×`），适合短促干脆的发卡弯快蓄快喷（Tier 1–2 / 3）。
   - **中倾角高速 90° / 折返弯（`14° – 24°`）**：
     - 兼顾高速入弯与稳健抓地，适合连续 S 弯与都市高架匝道。
   - **大倾角碗状 U 型弯（`28° – 35°`，如赞德沃特 / 纽北卡鲁塞尔）**：
     - 弯心向心支持强，车速维持在 `87%–97%` 极速；蓄气节奏平滑拉长（`bankChargePace ≈ 0.78×`），可稳定维持 3–4 秒超长横滑并获得最高 `+50%` 氮气充能加成。

3. **安全几何与零穿模铁律**
   - **无自交间距**：任意非相邻路段（沿赛道间隔 > 180m）的 3D 最小距离必须 **`>= 100m`**。
   - **零桥墩/地形穿模**：
     - 高架桥 T 型混凝土横梁必须跟随赛道真实倾角 `bankQuat` 旋转，并下沉至 `-4.35 * up`（高于箱梁底面净空 ≥ 3.35m）。
     - 桥墩立柱顶部按左右偏移位置在倾斜箱梁底面的真实高度截断，确保在 `35°` 倾角下仍低于路面 `≥ 3.3m`。
     - 山地 3D 地形必须按 `nearestY - halfWidth * sin(|bank|) - 8.5m` 加深开挖，且两侧净空 `>= halfWidth + 26m`。
     - 树木最小离路距 `>= halfWidth + 9.5m`，隧道顶部大型设备最低点离路面 `>= +18m`。
   - **功能道具不重叠**：
     - 地面加速带（`boostPads`）与飞跃跳台（`jumpRamps`）之间在归一化参数 `t` 上至少错开 `0.015`（~55m）以上；跳台不得置于隧道区间（`tunnelZones`）内，且跳台落点距离下一个急弯至少留出 `120m` 落地制动缓冲。

4. **弯前视觉预告标准**
   - 所有曲率 `|κ| > 0.006` 的弯道入口前自动生成 **150m / 100m / 50m** 距离刹车牌 + 弯外侧反光黑黄导向牌 + 内外侧 FIA 红白立体路肩。
   - `CarPhysics.scanUpcomingCorner()` 扫描前方 `30m – 210m`（触发阈值 `0.0052 / 0.0062`），驱动顶部 `#corner-callout` 实时提示弯向、是否发卡弯、倾角与剩余距离。

## 二、 现代街机漂移物理设计规范（`CarPhysics.ts`）

1. **车头朝向与速度矢量真解耦**
   - `yawOffset`：车辆实际速度方向（相对赛道切线）。
   - `headingYaw = yawOffset + slipAngle`：车头视觉与动态朝向；真实侧滑角 `slipAngle` 在 `12° – 41°` 之间随玩家转向输入实时变化，并驱动前轮自动反打（Counter-Steer）。
   - **出弯零甩尾铁律**：结束漂移瞬间保持 `yawOffset` 连续，立即令 `headingYaw = yawOffset`、`angularVel = 0`，仅让 `visualSlipAngle` 平滑回正，杜绝出弯猛拉撞墙。

2. **双触发起漂 + S 弯无缝换向**
   - **手刹起漂**：按住 `Space`（手机端 `DRIFT`）。
   - **点刹起漂（Brake-to-Drift）**：车速 > `130 km/h`（`36 m/s`）且打方向时轻点 `S / ↓`（或手机 `BRAKE`，< 0.28s）自动锁入漂移。
   - **S 弯无缝换向**：漂移中当前弯即将结束（`frame.curvature * driftDir < 0.0018`）且前方 `38m` 进入反向急弯（`<-0.0046`）时，反打方向持续 `>= 0.11s` 即可自动结算上一段漂移并丝滑切换至新弯方向，无卡死感；同时 `scanUpcomingCorner()` 遇曲率符号反转立即截断，保证连续蛇形弯始终精准提示眼前下一弯的方向。

3. **内弯贴路肩缓冲 & 外弯防撞柔和限幅**
   - 利用 `innerClearance` 与 `outerClearance` 渐变系数，在距内/外护栏 `2.6m – 8.1m` 范围内柔和衰减横向切入角，让玩家贴着 FIA 红白路肩丝滑擦弯而不猛撞护栏。

4. **漂移禁氮干脆切断规则（默认关闭「漂移同步喷气」）**
   - 当 `allowDriftNitro === false` 时，进入或处于漂移期间立即关闭 `isNitroActive`、`isSuperNitro`、`overdriveStage`，并同步清空残留的 `miniBoostTimer` 与 `boostPadTimer`、屏蔽排气管橙色尾焰与高速光带拖尾，确保漂移过程干净纯粹、零残余火焰；开启「漂移同步喷气」开关后允许自由叠加。

5. **超长直道综合赛道独立双开关辅助（极境环岛 / 曼岛 TT / 超级秋名山专属，默认全关！）**
   - 普通短程赛道（5 张）与纯技术发卡弯漂移山道（怒江 72 拐、极光星湾）始终保持 100% 纯原版手动氮气与基础极速。
   - 仅对 `island / manx / akina` 三张具备 `1km+` 笔直大直道的超长综合赛道提供**两枚互相独立的默认关闭开关**（主菜单与暂停页均可热切换并持久化至 `localStorage`）：
     - **开关 1 · `🚀 长道超频`（`enableStraightOverdrive`，默认 `false`）**：开启后在直道持续满油解锁一阶 `DRS OVERDRIVE I`（`2.0s` / `+52 km/h` / 碳纤尾翼放平 / `6.2/s` 回氮）→ 二阶 `HYPER OVERDRIVE II`（`5.2s` / `+104 km/h` / `~475–495 km/h` / `9.2/s` 回氮）与出弯零掉速惯性锁存（`momentumFloor` + `scrubLambda = 0.35` + 键盘轻点 `A/D` 抗误杀）；关闭时完全回归原版基础极速（`~365 km/h`），不产生自动提速或蓝焰。
     - **开关 2 · `⚡ 长道满氮`（`enableHyperNitro`，默认 `false`）**：开启后仅在几何自动识别的笔直超长直道（极境环岛 1 段 `6.2%`；60.7 km 曼岛 5 段 `20.7%`；27.2 km 超级秋名山 3 段 `21.1%`，5 大蛇形区与五连发卡 0% 误触发）点亮 3D 入口/出口光门、路肩青色光带、小地图金青高亮并锁定 `100% ∞ 无限氮气`；关闭时彻底隐藏所有 3D 光门/光带/小地图高亮且所有赛车（含 AI）均消耗常规氮气。
   - 尾流（Slipstream）判定范围放宽至 `80m / ±4.6m`，吸尾流提供 `13.5/秒` 氮气回充（开启超频时加速充能 `1.5×`）。

## 三、 新赛道上线验收标准（强制自动化验证）

每新增或修改一条赛道，必须运行两套无头校验脚本并通过：
1. **净空检查**（`check_clearance.ts`）：确认所有路段 `lowEdgeAboveFloor > 5m`、`capBelowRoad >= 3.3m`、`colCornerBelowRoad >= 3.3m`。
2. **四模式物理全跑仿真**（`test_drift.ts`）：
   - `minSep3D >= 100m`（无自交）；
   - `BRAKE_TAP` 模式整圈 `wallHits <= 1`；
   - `DRIFT` 模式圈速显著快于 `GRIP_ONLY` 且 `wallHits <= 3`；
   - 每个设计的 U 型弯 / 90° 弯均能自然触发完整漂移并获得 Tier 1–3 出弯加速。

## 四、 超长环岛 / 1:1 真实 60.7 km 赛道架构规范（Mega Island Grand Circuit）

当赛道总长超过 `4,500m`（如 `apex-island` `11.9 km` 与 1:1 真实全长 `isle-of-man` `60.725 km`）时，需同步满足以下扩展规范：
1. **动态样条精度与 O(1) 空间哈希（`TrackSpline.ts`）**：
   - 显式设置 `curve.arcLengthDivisions = Math.max(200, pts.length * 16)`，确保 130+ 控制点超长样条弧长采样绝对均匀。
   - 标准赛道（`<= 4,500m`）保持 `sampleCount = 1500`；`10–35 km` 按 `~2.6m/段` 采样；`> 35 km`（如 `60.725 km`）按 `~3.0m/段` 扩展至 `20,242` 段；内置 240m 2D 空间哈希 `getNearestRoadInfo()` 使全岛净空与地标查询达 O(1) 级耗时。
   - 发车直道与跳台坡道倾角展平使用物理米制缓冲区；弯前 `150m/100m/50m` 距离牌统一采用 `InstancedMesh`（全图仅 3 次绘制调用）。
2. **节奏叙事、真实地标分区与全局圈数选择**：
   - **怒江 72 拐盘山天路（`nujiang-72`，`7.32 km`，默认 2 圈，纯正发卡弯漂移山道）**：独立配置于 `src/config/nujiangTrack.ts`，采用 `makeHairpin()` 精确 5 点半圆弧生成器避免内侧护栏折角，路宽收紧至 `24m`、最紧弯半径 **`R = 39m`**（比常规高速弯急 2–3 倍）、弯道倾角控制在写实的 `7°–15°`（`maxBankDeg = 18°`）；以 4,658m 业拉山垭口（`Y = 172m`）发车，连续 7 连层叠“之”字形下坡发卡弯（`minSep3D = 111.2m`）俯冲 154m 至碧绿怒江大峡谷（`Y = 18m`），穿越红钢怒江大桥与 200m G318 穿山石洞后再经 5 连上坡发卡弯重返垭口；配套 `200×200` 横断山红岩雪峰零穿模山体（`minTerrainClearance = +9.50m`）、6 组飘动藏族五彩经幡与 3 座藏式白塔，单圈漂移总长超 `3.6–4.3 km`（50%–60% 路程处于横滑漂移状态）。
   - **极光星湾 24 弯迷宫（`aurora-fjord`，`20.76 km`，默认 1 圈 ≈ `3:24`，纯正放射状超长漂移迷宫）**：独立配置于 `src/config/auroraFjordTrack.ts`，精准还原 11 触角放射状星形峡湾轮廓（北冠 4 连纵向发卡、东南双礁臂、深探星心折返谷、正南深渊臂、西南巨钳勾弯、西侧 3 连弯月尖角，共 24+ 组连环急弯），路宽 `25m`、最紧弯半径 `R = 32m`、`minSep3D = 123.0m`、`maxBankDeg = 20°`（不触发公路自动超频，保持纯粹漂移节奏）；配套 `220×220` 北欧玄武岩群岛与 222m 雪峰火山口（23,952 路沿检测点最小净空 `+9.48m`）、柔和羽化流动北极光幕布、红木渔村与雪峰旋转灯塔，单圈漂移总长 `4.7–6.2 km`。
   - **超级秋名山 · 蛇形天道（`super-akina`，`27.25 km`，默认 1 圈 ≈ `4:25`，综合蛇形漂移 + 超长直道大满贯）**：独立配置于 `src/config/superAkinaTrack.ts`，采用 `L_lead = L / √2` 的 `C²` 曲率连续余弦蛇形生成器 `makeSerpentine()`，串起 **5 大连续左右蛇形漂移区**（北岭 11 连巨蟒 + 苍松 6 连急蛇 + 山麓 7 连蛇道 + 赤城峡谷 9 连高速大蛇 + 榛名西壁 8 连登顶蛇梯，共 **41 组超长 S 弯**，单弯弧长 `135–195m` / `R = 39–64m`）、**秋名传奇五连层叠下坡发卡弯**，以及 **3 段 `1.6–2.6 km` 笔直超长直道**（榛名湖出发大直道 / 伊香保温泉穿山+跳台大直道 / 高岭穿山登顶大直道，支持两枚默认关闭的超长直道独立开关）；路宽 `26m`、`minSep3D = 134.4m`、总落差 `196m`，配套 `240×240` 榛名山夜色红枫松林山体（31,440 路沿检测点最小净空 `+7.76m`）、月夜榛名湖（岸线净距 `+162m`）、秋名山顶水塔与茶屋、9 座朱红鸟居、160 栋伊香保温泉旅馆与 10 座日系分段高速门架；单圈漂移里程高达 **`7.9–12.9 km`**（30/30 零撞墙）。
   - **极境环岛大满贯（`apex-island`，`11.9 km`，默认 2 圈）**：海港都市 -> 双塔跨海悬索桥 + 34° 海洋碗弯 -> 76m 火山松林鸟居与悬崖发卡 -> 1.3km 穿山弧形隧道 + 33° 卡鲁塞尔 -> 灯塔半岛 5°–9° 低倾角发卡 + 铃鹿 S 弯 -> 海湾跳台冲刺。
   - **曼岛 TT 斯奈菲尔环岛（`isle-of-man`，精确 `60,725m / 37.73 英里`，默认 1 圈 ≈ 8 分钟，支持 `1 / 2 / 3 圈` 自由切换）**：独立配置于 `src/config/isleOfManTrack.ts`，完整还原道格拉斯大看台 → Bray Hill → Quarterbridge → Braddan → Crosby → Ballacraine → Glen Helen → Cronk-y-Voddy → Kirk Michael → Ballaugh 飞跃石桥 → Quarry Bends → 3.5km Sulby 极速超频直道 → Kerrowmoar → Ramsey 6° 发卡 → Gooseneck → 荒凉无树的 18km A18 Snaefell 高地（Mountain Mile / 30° Verandah / Bungalow / Hailwood's Height 跳台 / 28° Windy Corner）→ Creg-ny-Baa 酒馆 → Brandish → Governor's Bridge 冲线。
3. **双层 60 km 零穿模地形架构（`SceneryBuilder.ts`）**：
   - 相机远裁面升至 `9,800m`，天空盒半径 `7,200m`，动态爱尔兰海面扩展至 `44 km × 44 km`。
   - **Layer A（沿路 12m 精度防折叠绿丘坡带）**：紧贴 60.7 km 公路两侧展开，内弯自动按 `0.72 / |κ|` 限幅防折回，路基核心严格 `<= pos.y - bankDrop - 10.5m` 并经 O(1) 跨路段安全钳位。
   - **Layer B（240×240 全岛宏山脉 + 547m 斯奈菲尔主峰）**：沿公路走廊宽域下挖 `>= 15m`（`macroClearance >= 108m`），在远景无缝接续 Layer A，全线 60,726 个路沿边缘检测点零穿模、总加载 `< 160ms`。
